# Changelog

## 1.2.0

- Added an integrated PDF viewer with page navigation.
- Added drag-to-select table regions and click-to-place column boundaries.
- Added user-guided OCR for the current page or all pages.
- Preserved blank cells by assigning OCR words to explicit geometric columns.
- Added double-click column header renaming with uniqueness validation.
- Improved automatic ruled-table OCR for image-only bank statements.
- Retained secure password prompting and bundled offline Tesseract OCR.

## 1.1.0

- Added bundled Tesseract OCR and PDFium rendering.
- Added secure password prompts for encrypted PDFs.
- Added editable data review, correction commands, template mapping, and XLSX/CSV/TXT export.
